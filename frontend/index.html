Deployment Steps

  1. Mount the MPU-6050 node on the machine casing near the bearing housing (nylon clamp, no drilling).
  2. Wire the sensor to the UNO Q per the I²C table. Power via USB-C (< 500 mW draw).
  3. Flash firmware: arduino-cli upload yantra_firmware.ino, set MACHINE_ID in config.h.
  4. Calibrate: hold BOOT 3 s → 30 s healthy baseline auto-captured to flash.
  5. Connect the node to the same Wi-Fi/LAN as this laptop. It auto-publishes to the cloud.
